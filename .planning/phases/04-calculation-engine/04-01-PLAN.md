Create `src/engine/energy.ts` with these functions:

**Internal helper (not exported):**
`escalatePrice(initialPrice: number, annualIncrease: number, referencePeriod: number): number[]`
- NRG-001: `price[0] = initialPrice, price[year] = price[year-1] * (1 + annualIncrease)`
- Returns array of length `referencePeriod + 1`

**Internal helper:**
`computeEndUseCosts(consumption: number, treatedFloorArea: number, prices: number[], realRate: number, referencePeriod: number): YearlyEnergyCosts`
- NRG-002..006: For each year 1..N:
  - `nominal[year] = consumption * treatedFloorArea * prices[year]` (kWh/m2 * m2 * EUR/kWh)
  - `actualized[year] = nominal[year] / (1 + realRate)^year` -- uses RR (real rate), NOT Rint
  - `cumulated[year] = cumulated[year-1] + actualized[year]`
- Year 0: nominal[0] = 0, actualized[0] = 0, cumulated[0] = 0
- All arrays length = referencePeriod + 1

**Main export:**
```typescript
export interface EnergyCostResult {
  heating: YearlyEnergyCosts;
  cooling: YearlyEnergyCosts;
  dhw: YearlyEnergyCosts;
  household: YearlyEnergyCosts;
  pv: YearlyEnergyCosts;
}

export function computeEnergyCosts(
  input: VariantInput,
  realRate: number,
): EnergyCostResult
```

Implementation logic:
1. For each pair in END_USE_PAIRS (Heating, Cooling, DHW, Household):
   - Find matching EnergyEndUseInput(s) from input.energyInputs
   - For dual-system pairs (Heating 1+2, Cooling 1+2, DHW 1+2): sum consumptions from both systems before computing costs. Each system may use a different energy source for price escalation, so compute each system's costs separately then sum the YearlyEnergyCosts arrays element-wise.
   - For single-system (Household): compute directly
   - Look up EnergySourcePrice by energySourceIndex from input.energyPrices
   - If an end-use is not present in energyInputs, return zero-filled YearlyEnergyCosts

2. For PV (NRG-007):
   - Find PV_PRODUCTION in input.energyInputs
   - **CRITICAL**: PV price escalation always uses energy source index 13 ("Electricity from Photovoltaics"), NOT the dynamic lookup. This is verified from Excel: Calc!E28 = `D28 + PI!$G$143 * D28` where G143 = source index 13.
   - PV consumption = pvProductionKwh (if present) or specificConsumption * treatedFloorArea
   - PV costs are positive values in the YearlyEnergyCosts (subtraction happens in aggregate module)

3. Handle missing energy inputs gracefully -- if no heating inputs exist, return zero-filled arrays.

Import from types.ts: VariantInput, YearlyEnergyCosts, EnergySourcePrice, END_USE_PAIRS, EnergyEndUseInput.

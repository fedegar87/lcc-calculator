**Implementation logic:**

**AGG-001..004 (Construction costs):**
- AGG-001: `totalMaterials = sum(costItems[].materialCost)`
- AGG-002: `totalLabor = sum(costItems[].laborCost)`
- `totalOther = sum(costItems[].otherCost)`
- AGG-003: `totalConstruction = totalMaterials + totalLabor + totalOther`
- AGG-004: `constructionByCategory` = group costItems by category, sum (material + labor + other) per category

**AGG-005..007 (Non-construction, design, site management):**
- AGG-005: `nonConstructionCosts = landCost + enablingCosts + planningFees + userSupportPropMgmt + userSupportCharges + userSupportAdmin + financeCost`
- AGG-006: `designCosts = wlcInput.designCostsTotal` (pre-aggregated, per rule 10)
- AGG-007: `buildingSiteManagement = wlcInput.siteManagementCostsTotal` (SEPARATE from design per DEC-010)

**CAL-001..004 (Energy aggregation at reference period):**
- CAL-001: `energyConsumed = heating.cumulated[refPeriod] + cooling.cumulated[refPeriod] + dhw.cumulated[refPeriod] + household.cumulated[refPeriod]`
- CAL-002: `energyProduced = pv.cumulated[refPeriod]`
- (CAL-003: netEnergy = consumed - produced -- not stored separately, used in O&M)
- (CAL-004: energyCostPerM2 -- not in LCCResult, can compute if needed)

**AGG-008..011 (O&M):**
- AGG-008: `operationAndMaintenance = energyConsumed - energyProduced + maintenance.totalMaintenance`
  - Uses CAL-001 (consumed cumulated at refPeriod) - CAL-002 (produced cumulated at refPeriod) + CAL-007 (total maintenance at refPeriod)

**AGG-012..013 (LCC, WLC):**
- AGG-012: `lcc = designCosts + totalConstruction + operationAndMaintenance + buildingSiteManagement`
- AGG-013: `wlc = lcc + nonConstructionCosts`

**AGG-014 (KPIs):**
**CRITICAL -- KPI divisor is "investment cost", NOT LCC:**
- `investmentCost = totalConstruction + designCosts + buildingSiteManagement`
- Verified from Excel: B63 = B65 + B57 + B61

Helper: `safeRatio(num, denom) => denom === 0 ? null : num / denom`

- `kpiDesignOverLCC = safeRatio(designCosts, investmentCost)` -- Note: field name says "OverLCC" but actual divisor is investmentCost per research finding. Add inline comment.
- `kpiConstructionOverLCC = safeRatio(totalMaterials, investmentCost)` -- B83 = B66/B63 (materials only)
- `kpiLaborOverLCC = safeRatio(totalLabor, investmentCost)` -- B84 = B71/B63
- `kpiOMOverLCC = safeRatio(operationAndMaintenance, investmentCost)` -- B85 = B76/B63
- `kpiLCCPerM2 = safeRatio(lcc, treatedFloorArea)` -- per m2 uses area, not investment cost
- `kpiWLCPerM2 = safeRatio(wlc, treatedFloorArea)` -- per m2 uses area

No rounding in this module -- rounding happens in the orchestrator.

**Output assembly and rounding:**

Create two helpers (internal, not exported):
```typescript
function roundCurrency(v: number): number {
  return Math.round(v * 100) / 100;
}
function roundRate(v: number): number {
  return Math.round(v * 10000) / 10000;
}
```

Apply rounding to the FINAL LCCResult only -- never to intermediate values:
- All monetary values (costs, totals, KPI per-m2): roundCurrency
- Rates (realInterestRate): roundRate
- KPIs (ratios): roundRate (4 decimal places for ratios too)
- Yearly arrays: roundCurrency for each element
- income fields: roundCurrency for monetary, roundRate for payback years (keep 4dp)
- null values: preserve as null (don't round null)

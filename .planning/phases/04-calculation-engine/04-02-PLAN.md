```typescript
export interface MaintenanceCostResult {
  elements: number[];      // MNT-001: building element maintenance per year
  elementsCumulated: number[]; // MNT-002: cumulated
  services: number[];      // MNT-003 + MNT-004: building service maintenance per year (includes replacements)
  servicesCumulated: number[]; // cumulated services
  total: number[];         // elements + services per year
  totalCumulated: number[];// cumulated total
  // CAL-005..008 values at referencePeriod
  totalMaintenanceElements: number;  // CAL-005
  totalMaintenanceServices: number;  // CAL-006

  maintenanceCostPerM2: number;      // CAL-008 (0 if area=0)
}
```

**Main export:**
```typescript
export function computeMaintenanceCosts(
  input: VariantInput,
  config: EngineConfig,
): MaintenanceCostResult
```

**Implementation logic:**

**1. Building Element Maintenance (MNT-001, MNT-002):**
- Sum totalConstruction from costItems where CATEGORY_MAINTENANCE_MAP[category] === 'building_element'
  - totalConstruction = sum of (materialCost + laborCost + otherCost) for each building_element category item
- For each year 1..N:
  - `elements[year] = totalConstruction * buildingElementMaintenancePercent / (1 + interestRate)^year`
  - Uses `input.interestRate` (Rint, nominal) -- NOT real rate
- `elements[0] = 0`
- `elementsCumulated[year] = elementsCumulated[year-1] + elements[year]`

**2. Building Service Maintenance (MNT-003, MNT-004):**
- For each serviceComponent in input.serviceComponents:
  - Look up EN15459 component via `getEN15459Component(en15459ComponentIndex)`
  - Get lifespan = component.lifespanAvg (use 0 if component not found)
  - Get maintenancePct = component.maintenancePctAvg (use 0 if null or not found)
  - Track replacementsUsed counter per component (reset for each component)
  - For each year 1..N:
    - Check if replacement year: `year > 0 && lifespan > 0 && year % lifespan === 0 && replacementsUsed < config.maxReplacementCycles`
    - If replacement year:
      - Determine exponent:
        - If `config.formulaMode === 'excel_replica'` AND this is the LAST component in the array (index === serviceComponents.length - 1):
          - **MNT-BUG-001**: exponent = 9 (column I reference, constant)
        - Else: exponent = year (correct behavior)
      - `cost = constructionCost / (1 + interestRate)^exponent`
      - Increment replacementsUsed
    - If not replacement year:
      - `annualMaintenance = constructionCost * maintenancePct`
      - `cost = annualMaintenance / (1 + interestRate)^year`
  - Sum all component costs per year into services[] array
- `services[0] = 0`
- `servicesCumulated[year] = servicesCumulated[year-1] + services[year]`

**3. Totals and CAL values:**
- `total[year] = elements[year] + services[year]`
- `totalCumulated[year] = totalCumulated[year-1] + total[year]`
- CAL-005: `totalMaintenanceElements = elementsCumulated[referencePeriod]`
- CAL-006: `totalMaintenanceServices = servicesCumulated[referencePeriod]`
- CAL-007: `totalMaintenance = totalMaintenanceElements + totalMaintenanceServices`
- CAL-008: `maintenanceCostPerM2 = treatedFloorArea > 0 ? totalMaintenance / treatedFloorArea : 0`

**Critical rules:**
- ALL discounting uses interestRate (Rint), NOT real rate. This is the intentional asymmetry (DEC-005).
- MNT-BUG-001 only affects the LAST service component AND only during replacement years AND only in excel_replica mode.
- No rounding in intermediate calculations.
- Handle empty serviceComponents array (return zero-filled services arrays).
- Handle empty costItems or no building_element categories (return zero-filled elements arrays).
- All arrays length = referencePeriod + 1.

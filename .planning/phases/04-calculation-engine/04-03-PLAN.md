```typescript
export interface ResidualValueResult {
  totalResidualValue: number;
  componentResiduals: { name: string; residual: number }[];
}
```

**Main export:**
```typescript
export function computeResidualValue(
  serviceComponents: ServiceComponentInput[],
  referencePeriod: number,
  realRate: number,
): ResidualValueResult
```

**Implementation logic (RES-001, ISO 15686-5):**

For each service component:
1. Look up EN15459 component via `getEN15459Component(en15459ComponentIndex)`
2. Get lifespan = component.lifespanAvg (use 0 if not found)
3. If lifespan <= 0: residual = 0 (skip)
4. `remainingLife = lifespan - (referencePeriod % lifespan)`
5. `fraction = Math.max(0, remainingLife / lifespan)`
6. `residual = constructionCost * fraction / Math.pow(1 + realRate, referencePeriod)`
   - When `referencePeriod % lifespan === 0`: remainingLife = lifespan, fraction = 1.0
   - This is correct per ISO 15686-5: component was just replaced, full value remains

Sum all component residuals for totalResidualValue.

**Key rules:**
- Only applies to building services (B*, C* categories). The orchestrator will pass only service components, so this module doesn't filter by category -- that's the caller's responsibility.
- Building elements have lifespan = referencePeriod conceptually, so `referencePeriod % referencePeriod = 0`, giving fraction = 1.0 and full residual. But per the implementation plan, building elements DON'T get residual value computed. The caller simply doesn't pass them.
- Uses RR (real rate), NOT Rint.
- No rounding.
- Handle empty serviceComponents array (return 0).

Import from types.ts: ServiceComponentInput.
Import from constants.ts: getEN15459Component.

```typescript
export interface IncomeResult {

  netPresentValue: number;
}
```

**Main export:**
```typescript
export function computeIncome(
  incomeInput: IncomeInputData | undefined,
  lcc: number,
  referencePeriod: number,
  realRate: number,
): IncomeResult | null
```

**Implementation logic:**

If `incomeInput` is undefined or null, return null (no income data provided).

**INC-001 (Net annual income):**
```
rentIncome = sum of (monthlyPerM2 * area * 12 - taxes) for each rent
otherIncome = sum of (amount - taxes) for each otherIncome
netAnnualIncome = rentIncome + otherIncome
```
- Each rent: `monthlyPerM2 * area * 12` gives annual rent, then subtract taxes
- Each otherIncome: `amount - taxes`

**INC-002 (Simple payback):**
- `simplePaybackYears = netAnnualIncome > 0 ? lcc / netAnnualIncome : null`
- Returns null if income is zero or negative (no payback possible)

**INC-003 (NPV of income stream):**
- `npvIncomeStream = sum(netAnnualIncome / (1 + realRate)^year, year=1..referencePeriod)`
- `netPresentValue = npvIncomeStream - lcc`

**Key rules:**
- Uses RR (real rate) for NPV discounting.
- lcc is passed as parameter (computed by aggregate module).
- If netAnnualIncome is zero or negative, payback is null.
- No rounding.
- Handle empty rents/otherIncomes arrays.

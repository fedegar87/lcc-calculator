       - State: `{ status: SaveStatus, setStatus: (s: SaveStatus) => void }`
       - SaveStatus type: `"idle" | "saving" | "saved" | "failed"`
       - The provider wraps the project layout so all form steps share save status

    2. Create `src/hooks/use-autosave.ts` ("use client"):
       - Generic hook: `useAutosave<T extends FieldValues>({ control, onSave, debounceMs?, enabled? })`
       - Parameters:
         - `control`: React Hook Form Control
         - `onSave`: `(values: T) => Promise<void>` -- async function that calls tRPC mutation
         - `debounceMs`: default 500 (per user decision)
         - `enabled`: boolean, default true
       - Implementation:
         - Use `useWatch({ control })` to get current form values
         - Keep a ref to previous serialized values (`JSON.stringify`)
         - On value change: clear previous timer, set new `setTimeout(debounceMs)`
         - When timer fires: compare with previous values (CRITICAL: prevents infinite loop per pitfall #2), if different → call onSave
         - Track save status: set "saving" before call, "saved" on success, "failed" on error
         - Return `{ status: SaveStatus }` so the consuming component can pass to SaveStatusBadge
         - Use the save status context from use-save-status.ts to broadcast status globally
       - IMPORTANT: Do NOT reset form from server response to prevent infinite save loops

    3. Create `src/components/forms/shared/currency-input.tsx` ("use client"):

       - onValueChange: `(vals) => onChange(vals.floatValue ?? 0)`
       - Show field error from RHF fieldState below input

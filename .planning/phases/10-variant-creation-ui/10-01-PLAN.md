  <name>Task 1: Add variant creation button to VariantTabs</name>
  <files>src/components/project/variant-tabs.tsx</files>
  <action>
Modify `VariantTabs` component to include an "Add" button inside TabsList:

1. **Extend VariantTabsProps** to include `projectId: string` (needed for mutation).

2. **Import dependencies:**
   - `useMutation` from `@tanstack/react-query`
   - `useQueryClient` from `@tanstack/react-query`
   - `useTRPC` from `@/server/trpc/client`
   - `toast` from `sonner`
   - `Plus`, `Loader2` from `lucide-react`

3. **Add helper function** `getNextVariantLabel(variants)`:
   - Create a Set of existing labels
   - If `VARIANT_1` not in set, return `"VARIANT_1"`
   - If `VARIANT_2` not in set, return `"VARIANT_2"`
   - Otherwise return `null` (all slots filled)

4. **Add helper function** `humanLabel(label)`:
   - `"VARIANT_1"` -> `"Variant 1"`
   - `"VARIANT_2"` -> `"Variant 2"`
   - Fallback: return label as-is

5. **Add mutation** inside component using `useMutation`:
   ```
   const addVariant = useMutation(
     trpc.project.addVariant.mutationOptions({
       onSuccess: (data) => {
         toast.success(`${humanLabel(data.label)} created`);
         queryClient.invalidateQueries({ queryKey: trpc.project.getById.queryKey({ projectId }) });
         onVariantChange(data.id);
       },
       onError: (err) => {
         toast.error(err.message);
         queryClient.invalidateQueries({ queryKey: trpc.project.getById.queryKey({ projectId }) });
       },
     })
   );
   ```

6. **Compute visibility:**
   ```
   const nextLabel = getNextVariantLabel(variants);
   const canAdd = nextLabel !== null;
   ```

7. **Render + button** as last child inside TabsList (after the map):
   - Only render if `canAdd` is true
   - Use a `<button>` element (not TabsTrigger) with:
     - `onClick={() => addVariant.mutate({ projectId, label: nextLabel! })}`
     - `disabled={addVariant.isPending}`
     - Tailwind classes for inline tab-like appearance: `inline-flex items-center gap-1 px-3 py-1.5 text-sm font-medium rounded-md text-muted-foreground hover:text-foreground hover:bg-muted transition-colors disabled:opacity-50 disabled:pointer-events-none`
   - Content: show `<Loader2 className="h-3.5 w-3.5 animate-spin" />` when `isPending`, else `<Plus className="h-3.5 w-3.5" />`
   - Text label: "Add"

8. **Tab label display:** Update the TabsTrigger render to show human-readable labels:
   - `"BASE"` -> `"Base"`
   - `"VARIANT_1"` -> `"Variant 1"`
   - `"VARIANT_2"` -> `"Variant 2"`
   - Use `humanLabel()` or a simple mapping.

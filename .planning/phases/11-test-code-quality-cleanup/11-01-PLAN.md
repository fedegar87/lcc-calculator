# Plan 11-01: Code Deduplication and API Boundary Validation

## Goal

Remove duplicate `d()` and `resolveDetailCost()` helpers from variant.ts and cost-item.ts (import from _shared.ts instead), add `validateVariantInput` calls at tRPC calculation and export boundaries, and document useQueries as the intentional batch calculation pattern.

## Must-Haves (goal-backward)

- [ ] No duplicate `d()` function in variant.ts or cost-item.ts -- imported from `_shared.ts`
- [ ] No duplicate `resolveDetailCost()` in cost-item.ts -- imported from `_shared.ts`
- [ ] `validateVariantInput` called BEFORE `calculateLCC` in calculation.ts
- [ ] `validateVariantInput` called BEFORE `calculateLCC` in both export.ts mutations
- [ ] Validation failures throw `TRPCError` with code `BAD_REQUEST`
- [ ] useQueries pattern documented with comment in variant-comparison.tsx
- [ ] TypeScript compiles without errors
- [ ] Existing tests still pass

## Task 2: Add validateVariantInput at tRPC boundaries

### Actions

1. **Edit `src/server/trpc/routers/calculation.ts`:**
   - Add import: `import { validateVariantInput } from "@/engine/validation";`
   - After `const variantInput = buildVariantInput(variant);` (line 69), add:
     ```typescript
     const validationErrors = validateVariantInput(variantInput);
     if (validationErrors.length > 0) {
       throw new TRPCError({
         code: "BAD_REQUEST",
         message: `Input validation failed: ${validationErrors.join("; ")}`,
       });
     }
     ```

2. **Edit `src/server/trpc/routers/export.ts`:**
   - Add import: `import { validateVariantInput } from "@/engine/validation";`
   - In `generatePdf` mutation, after `const variantInput = buildVariantInput(variant);` (line 117), add the same validation block
   - In `generateExcel` mutation, after `const variantInput = buildVariantInput(variant);` (line 220), add the same validation block

3. **Verify TypeScript compilation:**
   ```bash
   npx tsc --noEmit
   ```

### Success Criteria
- `validateVariantInput` is called in calculation.ts before calculateLCC
- `validateVariantInput` is called in both export.ts mutations before calculateLCC
- TRPCError with BAD_REQUEST thrown on validation failure
</task>

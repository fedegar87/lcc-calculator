# Plan 11-02: Edge Case Tests for Calculation Engine

## Goal

Create `edge-cases.test.ts` with structural tests for calculation engine degenerate inputs: zero investment cost, empty energy inputs, single cost item, extreme reference periods, 0% rates, and zero treated floor area. No golden-value assertions -- only no-crash + shape + finite-number checks.

## Must-Haves (goal-backward)

- [ ] `src/engine/__tests__/edge-cases.test.ts` exists and compiles
- [ ] All edge case tests pass
- [ ] Tests cover: zero investment cost, empty energy inputs, single cost item only, extreme reference periods (1 year, 100 years), 0% interest rate and inflation rate, zero treated floor area
- [ ] Assertion style: no-crash + structural checks (valid LCCResult shape, finite numbers)
- [ ] No golden-value assertions

<task id="1">
## Task 1: Create edge-cases.test.ts

### Actions

1. **Create `src/engine/__tests__/edge-cases.test.ts`** with the following test structure:

   - **Helper:** `minimalValidInput()` function returning a VariantInput with minimal valid data (referencePeriod=30, small rates, empty arrays for energyInputs/costItems/serviceComponents/designCosts, zero WLC values, treatedFloorArea=500)

   - **Helper:** `expectValidResult(result: LCCResult)` function that checks:
     - result is defined
     - result.lcc is a finite number
     - result.wlc is a finite number
     - result.engineVersion is a string
     - result.formulaMode is a string
     - result.realInterestRate is a finite number

   - **Test group: "zero investment cost"**
     - Input with costItems=[], serviceComponents=[], designCosts=[]
     - Verify: no crash, LCC is 0 or finite, KPIs handle division gracefully (null when denominator is 0)

   - **Test group: "empty energy inputs"**
     - Input with energyInputs=[]
     - Verify: no crash, energy-related fields are 0 or finite arrays

   - **Test group: "single cost item only"**
     - Input with exactly one costItem (e.g., A1_ROOFS with materialCost=10000)
     - Verify: no crash, construction costs reflect single item

   - **Test group: "extreme reference periods"**
     - Period=1: minimal calculation, no crash
     - Period=100: maximum allowed, no crash, arrays have correct length

   - **Test group: "0% interest rate and inflation rate"**
     - Both rates set to 0
     - Verify: no crash, realInterestRate is finite (0% rates cause Fisher formula to return 0)

   - **Test group: "zero treated floor area"**
     - treatedFloorArea=0
     - Verify: no crash, KPI per-m2 values are null (division by zero handled)

   - **Test group: "no services"**
     - Input with serviceComponents=[]
     - Verify: no crash, maintenance services array is all zeros

   - **Test group: "no income"**
     - Input with incomeInput undefined
     - Verify: no crash, income is null

   - **Test group: "all-zero costs"**
     - All monetary values set to 0
     - Verify: no crash, LCC is 0 or finite

2. **Use patterns from existing `validation.test.ts`:**
   - Import from `vitest`: describe, it, expect
   - Import `calculateLCC` from `../index`
   - Import `VariantInput` and `LCCResult` types from `../types`
   - Follow same fixture-builder pattern

3. **Run tests:**
   ```bash
   npx vitest run src/engine/__tests__/edge-cases.test.ts
   ```

4. **Run full test suite to ensure no regressions:**
   ```bash
   npx vitest run
   ```

### Success Criteria
- edge-cases.test.ts compiles without errors
- All edge case tests pass
- No golden-value assertions present
- Full test suite passes

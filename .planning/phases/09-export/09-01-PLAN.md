  variantLabel  VariantLabel

Create `src/server/export/snapshot.ts`:
- `computeInputsHash(input: VariantInput, formulaMode: FormulaMode): string` -- Uses `createHash('sha256')` from `node:crypto`. JSON.stringify with a replacer that recursively sorts object keys for determinism. Returns hex digest.
- `getOrCreateSnapshot(db, params)` -- params: `{ projectId, variantLabel, engineVersion, formulaMode, variantInput, result, userId }`. Computes inputsHash, queries `db.resultSnapshot.findFirst({ where: { projectId, inputsHash } })`. If found, returns existing. If not, creates new `ResultSnapshot` with `inputs: variantInput as Json`, `outputs: result as Json`, `trigger: 'export'`, `inputsHash`, `createdById: userId`. Returns the snapshot record.

Create `src/server/export/chart-renderer.ts`:
- Import `renderToStaticMarkup` from `react-dom/server`, `sharp` from `sharp`, `React` from `react`.
- Import `BarChart, Bar, XAxis, YAxis, CartesianGrid, Legend, LineChart, Line` from `recharts`.
- Use `React.createElement` (NOT JSX) to avoid needing TSX extension on a server-only file. Actually, **use .tsx extension** for this file if needed, or use createElement. Research shows sharp handles SVG well.
- CRITICAL: Use hex colors (NOT oklch) for SVG rendering since sharp's librsvg may not support oklch. Convert: design=#5B8DEF, construction=#4CAF80, oAndM=#D4A843, siteManagement=#9B6FCC, energy=#5B8DEF, maintenance=#D4A843, total=#C8102E.
- `renderLCCStackedBarPng(result: LCCResult): Promise<Buffer>` -- Builds data array matching UI component structure. Uses `BarChart` with `layout="vertical"`, fixed `width=500, height=280`. All `isAnimationActive={false}`. Renders via `renderToStaticMarkup`, converts with `sharp(Buffer.from(svgString)).png().toBuffer()`.
- `renderCostEvolutionPng(result: LCCResult): Promise<Buffer>` -- Builds yearly data array (year, Energy, Maintenance, Total O&M) from cumulated arrays, same logic as UI `cost-evolution-line.tsx`. Uses `LineChart` with fixed `width=500, height=280`. All `isAnimationActive={false}`, `dot={false}`.
- IMPORTANT: Do NOT use `ResponsiveContainer` -- it requires browser DOM. Use fixed dimensions directly on chart components.

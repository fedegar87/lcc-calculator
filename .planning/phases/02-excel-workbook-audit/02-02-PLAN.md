  <action>
Create `docs/architecture-decisions.md` documenting all 10 architecture decisions with workbook evidence.

**Structure each decision as an ADR (Architecture Decision Record) with:**
- Decision ID and title
- Status: Accepted
- Context: Why this decision was needed (what workbook behavior prompted it)
- Decision: What was decided
- Rationale: Why this approach (with workbook evidence -- cell references, formula analysis)
- Consequences: What this means for the engine implementation

**The 10 decisions (sourced from `llc-implementation-plan.md` lines 583-645):**

**DEC-001: Numeric types**
- Prisma Decimal for DB, JS number in engine with controlled rounding
- Evidence: Building LCC precision is met by IEEE 754; Decimal prevents accumulation across DB writes

**DEC-002: Formula mode**
- Engine accepts `formulaMode`: 'excel_replica' | 'excel_bugfixed'
- Default: 'excel_bugfixed'. Snapshots record mode used.
- Evidence: MNT-BUG-001 (Maintenance!I62 exponent bug) is the primary mode toggle. NRG-BUG-001, NRG-BUG-002, MNT-BUG-002 also candidates for mode toggle.

**DEC-003: Replacement cycle cap**
- Excel checks only 1x, 2x, 3x lifespan via IF(OR()). Engine uses `year % lifespan === 0` with `maxReplacements` parameter (default 3).
- Evidence: MNT-004 formula `=IF(OR(I5=$H$37, I5=($H$37*2), I5=($H$37*3)), ...)`

**DEC-004: Year indexing**
- Year 0 = construction, discount factor = 1.0. Operations start year 1.
- Evidence: Calc!D7 = 0, energy costs start column E (year 1)

**DEC-005: Maintenance discount rate asymmetry**
- Maintenance: discounted with Rint (nominal). Energy: discounted with RR (real).
- Evidence: Maintenance!D5 refs PI!D121 (Rint), Calc!D8 refs PI!D125 (RR)

**DEC-006: Residual value (METHOD_IMPROVEMENT)**
- Excel has header but no formulas. Implement ISO 15686-5 formula.
- Evidence: Construction cost!BC2 = "RESIDUAL VALUE", all data cells empty. Results has no BC references.
- Formula: `cost * max(0, (lifespan - (refPeriod % lifespan)) / lifespan) / (1+RR)^refPeriod`

**DEC-007: Income analysis (METHOD_IMPROVEMENT)**
- Excel collects income data (PI rows 84-113) but never calculates with it.
- Evidence: No Results formula references any PI income cell.
- Implement: net annual income, simple payback, NPV of income stream.

**DEC-008: Cost category to maintenance mapping**
- A1-A10 = building elements (flat % maintenance)
- B1-B6, C1-C3 = building services (EN 15459 lookup)
- D1, E1 = no maintenance
- Evidence: Construction cost sheet category column structure, Maintenance sheet element rows (7-36) vs service rows (37-65)

**DEC-009: Interest rate UX format**
- Excel stores as basis points (Calc!C3=151 for 1.51%), converts via PI!D121=Calc!C3/10000.
- Web app: percentage input (1.51) -> decimal (0.0151) in DB and engine.

**DEC-010: Building site management separation**
- Design costs (Results!B57) and site management (Results!B61) are SEPARATE LCC components.
- Evidence: LCC formula Results!B62 = B57 + B65 + B76 + B61 (design + construction + O&M + site_mgmt)
- Engine returns both as distinct fields.

**Footer** with reference to source documents: `llc-implementation-plan.md`, `02-RESEARCH.md`, workbook path.

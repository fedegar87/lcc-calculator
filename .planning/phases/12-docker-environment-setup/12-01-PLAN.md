<task type="auto">
  <name>Task 1: Create docker-compose.yml with PostgreSQL 16</name>
  <files>docker-compose.yml</files>
  <action>
Create `docker-compose.yml` at project root with a single PostgreSQL 16 service:

```yaml
services:
  postgres:
    image: postgres:16-alpine
    container_name: lcczero-postgres
    restart: unless-stopped
    ports:
      - "5432:5432"
    environment:
      POSTGRES_USER: lccuser
      POSTGRES_PASSWORD: lccpass
      POSTGRES_DB: lccdb
    volumes:
      - lcczero-pgdata:/var/lib/postgresql/data

volumes:
  lcczero-pgdata:
```

Key decisions per CONTEXT.md:
- PostgreSQL 16 only, no pgAdmin, no Adminer
- No health check (keep it simple)
- Named volume `lcczero-pgdata` for data persistence
- `unless-stopped` restart policy so it survives host reboots
- Container name `lcczero-postgres` for easy identification
- Standard port 5432 (context leaves port choice to discretion)
  </action>
  <verify>
    <automated>docker compose config --quiet 2>&1 && echo "VALID" || echo "INVALID"</automated>
  </verify>
  <done>docker-compose.yml exists, passes config validation, defines postgres service with image postgres:16-alpine, named volume lcczero-pgdata, port 5432, and environment variables matching .env.example DATABASE_URL</done>

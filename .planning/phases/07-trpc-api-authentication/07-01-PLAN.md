<task type="auto">
  <name>Task 2: Rewrite tRPC context with auth session and create protectedProcedure + role middleware</name>
  <files>src/server/trpc/init.ts, src/server/trpc/middleware/auth.ts</files>
  <action>
**src/server/trpc/init.ts** - Rewrite the existing stub:
- Import `initTRPC, TRPCError` from `"@trpc/server"`, `superjson` from `"superjson"`, `auth` from `"@/lib/auth"`, `prisma` from `"@/lib/prisma"`
- `createTRPCContext` receives `{ headers: Headers }`, calls `const session = await auth.api.getSession({ headers })`, returns `{ db: prisma, session, user: session?.user ?? null }`
- Create `t` with `initTRPC.context<Awaited<ReturnType<typeof createTRPCContext>>>().create({ transformer: superjson })`
- Export `createTRPCRouter = t.router`, `createCallerFactory = t.createCallerFactory`, `baseProcedure = t.procedure`
- Create and export `protectedProcedure = t.procedure.use(async (opts) => { if (!opts.ctx.user) throw new TRPCError({ code: "UNAUTHORIZED" }); return opts.next({ ctx: { ...opts.ctx, user: opts.ctx.user, session: opts.ctx.session! } }); })`
- The `protectedProcedure` narrows `user` from `User | null` to `User` in downstream context

**src/server/trpc/middleware/auth.ts** - New file for role-based access:
- Export `requireProjectRole(...allowedRoles: ("OWNER" | "EDITOR" | "VIEWER")[])`
- Returns a tRPC middleware function (compatible with `.use()`)
- The middleware receives `opts` with `ctx.user.id` and `ctx.db` (from protectedProcedure context)
- Extract `projectId` from `opts.input` (cast to `{ projectId?: string }`)
- If no `projectId`, throw `TRPCError({ code: "BAD_REQUEST" })`
- Query `ctx.db.projectMember.findUnique({ where: { projectId_userId: { projectId, userId: ctx.user.id } } })`
- If no membership found, check if user is project creator: `ctx.db.project.findFirst({ where: { id: projectId, userId: ctx.user.id } })`
- If creator found, treat as implicit OWNER. If `"OWNER"` is in `allowedRoles`, allow. Otherwise throw NOT_FOUND.
- If neither member nor creator, throw `TRPCError({ code: "NOT_FOUND" })` (per user decision: 404 to hide project existence)
- If member found but role not in `allowedRoles`, throw NOT_FOUND
- If allowed, call `opts.next({ ctx: { ...opts.ctx, projectId, memberRole } })` adding `projectId` and `memberRole` to context

NOTE: Use `t.middleware()` pattern from tRPC v11, not raw function. Import `t` or the middleware creator from init.ts. Alternative: export `const middleware = t.middleware` from init.ts for use in this file.
  </action>

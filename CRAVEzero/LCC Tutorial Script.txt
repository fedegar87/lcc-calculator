Welcome to this tutorial for the LCC tool. I am going to show you how the tool works and how it is structured. You can see that the tool is divided in several sheets project information, WLC, LCC and results. The first three sheets are devoted to the data collection. 
In project information you will insert all the relevant information of your project. The data input is divided in different sections: First the project data then we have the data related to building surfaces and volumes. It follows a section where you should provide data about the energy calculation. We used the PHPP tool.
